# Daymark

A small, responsive daily task list that saves tasks in your browser.

## Run it

Open `index.html` in a browser. No build step, package install, or server is required.

## Features

- Add, complete, and delete tasks
- Edit tasks and filter by all, active, or completed
- Set due dates, categories, and priority levels
- See in-app reminders for tasks due today or overdue
- Switch between light and dark themes
- Export a JSON backup and import it later (import replaces the current browser list)
- Clear completed tasks
- See remaining tasks and completion progress
- Automatically save tasks in browser local storage
- Works on desktop and mobile screens

## Publish

Upload `index.html`, `style.css`, and `app.js` to a repository. The app can be hosted as a static site, including with GitHub Pages.
